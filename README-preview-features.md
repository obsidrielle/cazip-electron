# 文件预览功能增强

## 新增功能

### 1. 文本预览增强

#### 智能内容检测
- 不仅根据文件扩展名判断类型，还会分析文件内容
- 支持检测：JavaScript、TypeScript、Python、JSON、HTML、CSS、XML、Shell脚本等
- 自动识别文件编程语言并应用相应的语法高亮

#### 代码高亮
- 使用 Prism.js 提供语法高亮
- 支持多种编程语言：
  - JavaScript/TypeScript
  - Python
  - JSON
  - HTML/CSS
  - XML
  - Shell/Bash
  - SQL
  - YAML
  - Markdown

#### 搜索功能
- 实时搜索文本内容
- 显示搜索结果数量和当前位置
- 支持上一个/下一个搜索结果导航
- 自动滚动到搜索结果位置

#### 编辑功能
- 切换预览/编辑模式
- 实时编辑文本内容
- 显示未保存更改状态（文件名后显示*）
- 保存功能（需要后端支持）

### 2. 图片预览增强

#### 缩放功能
- 使用 react-zoom-pan-pinch 库
- 支持鼠标滚轮缩放
- 支持触摸板手势缩放
- 缩放范围：10% - 500%

#### 控制按钮
- 放大按钮
- 缩小按钮
- 重置缩放按钮
- 双击重置缩放

#### 平移功能
- 拖拽移动图片
- 适合查看大图的细节

### 3. 界面改进

#### 更大的预览窗口
- 窗口尺寸从 4xl 增加到 6xl
- 高度调整为 90vh，提供更多预览空间

#### 工具栏
- 文本预览：搜索框、语言显示、编辑/预览切换、保存按钮
- 图片预览：缩放控制按钮

#### 状态指示
- 显示检测到的文件类型/编程语言
- 显示搜索结果统计
- 显示未保存更改状态

## 使用方法

### 文本文件预览
1. 右键点击文本文件，选择"预览"
2. 系统会自动检测文件类型并应用语法高亮
3. 使用搜索框查找特定内容
4. 点击"编辑"按钮切换到编辑模式
5. 编辑后点击"保存"按钮保存更改

### 图片文件预览
1. 右键点击图片文件，选择"预览"
2. 使用工具栏按钮进行缩放操作
3. 拖拽图片进行平移
4. 双击图片重置缩放

## 支持的文件类型

### 文本文件
- .txt, .md, .json
- .js, .jsx, .ts, .tsx
- .py, .sh, .bash
- .html, .css, .xml
- .sql, .yml, .yaml
- .ini, .conf, .cfg
- .log, .csv

### 图片文件
- .jpg, .jpeg, .png
- .gif, .bmp, .webp
- .svg, .ico

## 技术实现

### 依赖包
- `prismjs`: 语法高亮
- `react-zoom-pan-pinch`: 图片缩放和平移
- `@types/prismjs`: TypeScript 类型定义

### 核心功能
- 智能文件类型检测
- 实时搜索和导航
- 文本编辑和保存
- 图片缩放和平移
- 响应式界面设计

## 注意事项

1. 文件大小限制已从 3MB 增加到 10MB
2. 保存功能需要后端 IPC 支持
3. 语法高亮在大文件时可能影响性能
4. 图片缩放功能支持现代浏览器的触摸手势
